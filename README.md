# Мир чая — Система управления каталогом и заказами

## 1. Название приложения
**Мир чая** — приложение для автоматизации продаж фасованного чая и чайных смесей (Тема 9, УП.11).

## 2. Используемые технологии
* **Язык программирования:** Python 3.13+
* **Графический интерфейс (GUI):** PySide6 6.8+
* **СУБД:** PostgreSQL 18.6
* **Драйвер базы данных:** psycopg2-binary 2.9+
* **Библиотеки для импорта:** pandas, openpyxl

## 3. Назначение и основные функции
Приложение предназначено для выбора позиций из каталога, оформления и управления заказами. 
Основные реализованные функции:
* **Каталог товаров:** отображение изображения, категории, производителя, наименования, состава, цены и остатков. Подсветка товаров с низким остатком (менее 3 упак.) цветом `#ff8080`.
* **Авторизация:** вход в систему по логину без пароля (с поддержкой ролей и режимом «Гость»).
* **Корзина:** выбор варианта упаковки (50г, 100г, 200г), добавление товаров, оформление заказа со списанием остатков.
* **Управление заказами:** просмотр списка заказов, просмотр состава, удаление заказов с возвратом остатков (доступно менеджерам и администраторам).
* **Фильтрация и поиск:** поиск по названию/описанию, фильтрация по категориям, сортировка по цене (возр/убыв) и алфавиту.
* **Скидки:** автоматический расчет скидки 25% на товары, на которые не было заказов за предыдущий календарный месяц.

## 4. Порядок подготовки базы данных и запуска приложения

### Шаг 1. Подготовка базы данных PostgreSQL
1. Установите PostgreSQL 18.6 и запустите pgAdmin.
2. Создайте пустую базу данных с именем `mir_chaya`.
3. Откройте **Query Tool** для созданной базы и выполните скрипт `src/db/mir_chaya.sql` (он создаст таблицы).
4. Откройте файл `src/app/main.py` и в классе `Database` (в методе `init_pool`) укажите ваш реальный пароль от PostgreSQL вместо `123`.

### Шаг 2. Импорт данных из Excel
1. Откройте терминал в папке `src/app`.
